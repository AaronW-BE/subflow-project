## Safe isolated-emulator acceptance recipe — all unchecked

Use only a confirmed disposable emulator/profile with synthetic data and no accounts. Record AVD/API/launcher, APK build identity, locale/font/theme, fixtures and observed results. Do not clear/uninstall/restore data on a real phone, change its clock, touch production records, or interact with external FX/billing providers. Keep network disabled; use existing offline rates. If a fixture requires an unavailable test hook/entitlement, mark it blocked rather than making provider calls or changing production configuration.

- [ ] **Fixtures:** on the isolated profile, create USD monthly 12; EUR monthly 10 (covered offline FX); a free record; paused USD monthly 8; unresolved expired trial with zero current cost and a positive post-trial price; valid today/future, past and invalid schedule examples where safely importable. Use a synthetic JSON fixture in the existing backup schema only for otherwise unenterable dates/missing-rate currency; never replace real data. Retain a copy of the synthetic input. Add a deleted record to verify exclusion.
- [ ] **Home subsets:** compare global totals/counts before and after search/category; tap each count, verify cleared filters and visible exit, then search inside the subset. All includes paused; reset restores ordinary grouping. Exercise paused-only, empty subset and zero matches. Verify unknown price entries remain last both ways. Check neutral invalid-date wording and valid next-event selection.
- [ ] **Coverage/analytics:** add a positive cost in a currency absent from offline coverage via a synthetic fixture; observe partial known amount, then unavailable rather than zero when it is the only positive contribution. Empty/free/current trials remain complete zero. Check category amounts remain visible while affected comparisons pause. Use a trial whose future charge lacks FX to verify independent current/forecast coverage; use a future-first-date record outside the horizon for the reverse case. Verify forecast includes elapsed current-month scheduled charges, while home events exclude past dates.
- [ ] **Budget:** in an existing isolated Pro-capable test environment only, set a budget and exercise add/edit, single/bulk resume, partial quota acceptance and undo through actual navigation. Unknown before/after/budget conversion must suppress monetary conclusions but retain success facts. Open a missing-FX original-currency budget dialog, type a draft, change available local inputs only if supported, and verify draft/currency retention and save/removal. Check JPY/KRW fractional validation. Do not purchase Pro for this check.
- [ ] **CSV:** export through Analytics to a local destination on the emulator only. Inspect BOM, exact header/status vocabulary against the owning spec, source currencies/amounts, quote/newline escaping and blank failed home cells; no annual column. Confirm JSON backup still uses its existing schema. Avoid cloud share targets.
- [ ] **Widget:** place both minimum short/tall sizes on an actual emulator launcher, resize, and inspect empty/all-paused/complete-zero/partial/unavailable inventory. Verify readable unclipped coverage, scrollable counts/events or no-events, locale/large-font/touch-exploration behavior. Tap body to home and each row to its own detail, including cold activity launch. Capture screenshots plus click observations; compilation is insufficient.
- [ ] **Refresh:** with only disposable fixtures, mutate records/home currency/language, background/resume, and change emulator date/timezone to check visible consistency and distinct reloads. If no safe local rate-publication hook exists, leave live-rate runtime refresh blocked; automated publication tests are not provider/device evidence. Observe launcher/system periodic behavior without promising midnight delivery; OEM/Doze/force-stop acceptance remains separate and unverified unless actually exercised on an isolated target.
